# 📊 Excel Sales Analytics Project

## 📌 Project Overview
This project focuses on analyzing sales data using Microsoft Excel to understand business performance, revenue trends, and product sales.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Charts & Dashboard
- Conditional Formatting

## 📈 Key Analysis
- Total Revenue Analysis
- Monthly Revenue Trends
- Month-over-Month Growth
- Top 10 Products
- Sales Performance Analysis
- Revenue Insights

## 📊 Dashboard
The dashboard provides a clear and interactive view of sales performance and business trends.

## 🎯 Project Objective
To transform raw sales data into meaningful business insights using Excel analytics and visualization techniques.
